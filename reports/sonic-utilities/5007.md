## R1 — availability failure escapes the per-target boundary

**Condition and consequence.** The topology declares `els0` and `els1`, while the CPO table has only `els1`. `CpoMapping.resolve_resource_ids(None, EXTERNAL_LASER_SOURCE)` returns both declared IDs. `get_resource_cpo_objects` raises immediately on `els0`; it never returns the list to `_run_firmware_operation` or `_show_firmware_version`. The healthy `els1` hook is not called and its version is not emitted. Selecting `els1` directly succeeds because its single lookup exists.

**Immutable evidence:** [resolver](https://github.com/sonic-net/sonic-utilities/blob/8fb199d6da3e909fea0cf2261ef4afd23f8e373a/cpoutil/main.py#L264-L286), [firmware target wrapper and loop](https://github.com/sonic-net/sonic-utilities/blob/8fb199d6da3e909fea0cf2261ef4afd23f8e373a/cpoutil/main.py#L2298-L2381), [fwversion resolution](https://github.com/sonic-net/sonic-utilities/blob/8fb199d6da3e909fea0cf2261ef4afd23f8e373a/cpoutil/main.py#L2577-L2603), [declared resource selection](https://github.com/sonic-net/sonic-utilities/blob/8fb199d6da3e909fea0cf2261ef4afd23f8e373a/cpoutil/mapping.py#L222-L237). `load_cpo_object_map` explicitly skips interfaces whose `get_cpo` returns None while retaining healthy interfaces; thus the missing-object state is supported by the actual initialization code, not just a fabricated malformed hook.

**Baseline classification.** The base resolver already raises on a missing CPO. Existing generic show/control semantics are not claimed to regress. The firmware and fwversion entry paths are new, and their new per-target contract is not met. [HLD 7.9](https://github.com/sonic-net/SONiC/blob/68ef12a9a83929905bc5a991d9d7c2dedb811941/doc/cpo-util/cpo-util-hld.md#L529-L545) distinguishes invalid selection from unavailable per-target objects.

**Smallest correction.** Validate the selector and enumerate declared IDs first; resolve each CPO/endpoint inside the firmware-specific per-target try block. Preserve fatal invalid-index behavior and existing unrelated callers. Record unavailable target labels, continue healthy targets, and retain a nonzero aggregate result. Add tests where one declared CPO is missing, not only where a present CPO has a missing endpoint or a hook raises.
