## Source assessment

### Production log correction

[Changed backend](https://github.com/sonic-net/sonic-linkmgrd/blob/5a4563b1ccd21bfbc915f4e165f778e49ea269a7/src/common/SwssLogBackend.cpp#L56-L62) passes `formatted_message.c_str()` as data to Common’s variadic `Logger::write`, using `"%s"` as the format. Actual pinned Common logger declaration and implementation confirm the printf/vsyslog contract.

The old call treated message content as a format string without corresponding arguments. The change correctly protects literal `%` content, preserving severity mapping and logger lifecycle. It is not an unrelated runtime change hidden in the build migration.

### Source inventory, flags and dependency ownership

The Common adapter separates public compilation context from the shared-library linking provider, avoiding unwanted static libnl ownership. Actual pinned compiler/runtime/public-CcInfo helpers, source-built Common distribution, target Boost metadata, library aliases and selected registry patches were inspected.
