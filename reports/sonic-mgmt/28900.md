## Summary
The existing GCU fixture applies expected-error filters to one selected DUT, while LogAnalyzer monitors all DUTs in its active collection. This patch adds one VS-only `e1000 … eth0: Reset adapter` exception to each DUT's analyzer, without copying the broader GCU ignore list to peers.

The change at `tests/generic_config_updater/conftest.py:80–86`:
- Checks `asic_type == "vs"` separately for each host; physical peers receive no new exception.
- Keeps selected-DUT selection and the original GCU list unchanged (`88–153`).
- Works with the provider's host-keyed dictionary and fresh function-scoped analyzers; disabled LogAnalyzer is guarded.
- Leaves link-CRC assertions, checkpoints, rollback, log markers and general error detection unchanged.

This intentionally applies throughout GCU test windows, not only the reproducing link-CRC case. The old, broader selected-DUT `Reset adapter` filter remains at line126: claims about preserved negative controls below refer to **peer DUTs**, not a newly tightened selected-DUT policy.
